# pair-wise-yf-57 野外巡护离线调查应用

## 源提示词摘要
巡护员离线记录观察、轨迹点、样本编号、风险等级和现场情况，回到有网络环境后同步给站点负责人。负责人复核重复观察、位置异常、证据缺失和能力范围外事项；多人修改同一记录时保留版本并允许合并，应用需要适配手机屏幕、电量、弱网和后台恢复。

## 技术栈
Taro 3 + React + TypeScript + NutUI + Redux Toolkit + React Hook Form + Zod。

## 同步与合并规则（已实现闭环）
- **逐条字段级三向合并**：观察记录、轨迹点、样本各自按「本地值 / 站里值 / 上次同步基线」逐字段合并，不做整记录覆盖。
- **同字段两边都改**：两份内容都保留（`conflicts[field] = {local, remote}`），记录进入冲突态，由站点负责人逐条确认取哪份；巡护员无权裁决。
- **没动的字段跟站里值走**：仅站里改过、本地未改的字段，同步时自动采用站里值，不产生冲突。
- **幂等上传**：站点按「类型 + 客户端ID」识别，同一条记录重复上传返回 duplicate，不会多出一份；同步队列只含 queued/failed，已 synced 的不重传。
- **断点续传**：同步中途断连时，已传成功的落为 synced，未传完的标记 failed；重试只补传未完成的记录。
- **坐标级联作废**：轨迹点坐标一变（坐标版本 +1），关联样本的核验结论立即作废并按新坐标自动重算（待负责人确认），关联观察的复核重置为待复核；站里端改坐标走同一套级联规则。
- **角色权限**：复核、核验、冲突裁决、轨迹点坐标修正仅站点负责人可执行；巡护员越权操作会被明确拒绝（记录不发生变化）。

## 演示入口（单页）
- 顶部切换「巡护员 / 站点负责人」身份，切换联网/无信号，可预设下次同步中途断连。
- 「站里端模拟」卡片可制造：远端单独改字段、同字段两边冲突、站里修坐标触发级联等场景。
- 「幂等演示」按钮把一条已同步记录再传一次，观察站里记录总数不变。
- 「重置全部演示数据」恢复种子场景。
